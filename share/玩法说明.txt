《折纸奇旅 · Origami GP》单文件便携版
=====================================

【怎么开始】
1. 解压后双击「折纸奇旅OrigamiGP.html」即可游玩（无需安装、无需联网）。
2. 推荐使用最新版 Chrome 或 Edge 浏览器打开。
   （若双击后没反应/空白，请右键该文件 → 打开方式 → 选择 Chrome/Edge。）
3. 需要浏览器支持 WebGL2（近几年的电脑默认都支持）。

【操作】
- W / ↑ 油门，S / ↓ 刹车/倒车
- A / ← 左转，D / → 右转
- Shift / 空格 漂移：按住并转向蓄力，0.8 秒蓝火花、1.6 秒金火花，松开获得小涡轮加速
- E / F / Enter 使用道具
- 手机/平板：在「设置」里开启触屏虚拟按键

【玩法】
- 大厅按 4 步配置：1 模式 → 2 纸张克重 → 3 选车手 → 4 选赛道，然后「开始比赛」。
- 大奖赛：8 名车手 3 圈竞速，吃「?」道具箱获得道具（胶带护盾/纸飞机冲刺/双面胶陷阱/折纸回旋镖）。
- 计时挑战：单人刷圈，会与你自己最佳纪录的半透明幽灵车同场。
- 纸张克重影响手感：80g 宣纸轻快、180g 道林纸均衡、320g 瓦楞卡纸稳重极速高。
- 右上角「?」看完整说明，「齿轮」调画质/阴影/触屏/音量。

【备选：本地服务器方式】
若单文件版在你的浏览器受限，可在有 Node.js 的电脑上于项目目录运行
  npm run dev      然后访问 http://localhost:5173
或 npm run build 后 npm run preview，访问 http://localhost:4173。
