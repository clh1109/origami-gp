# 3D 折纸模型放置目录 (GLB Models Directory)

你可以将从 **腾讯混元 3D / Tripo3D / Meshy** 等 AI 3D 工具导出的 `.glb` 模型直接放入此目录：

### 推荐放置文件名：
1. **`kart.glb`**：通用精致卡丁车车模（所有车手默认替换）
2. **`kart_fox.glb` / `kart_rabbit.glb` 等**：指定车手的专属车模（优先加载）
3. **`driver_fox.glb`**：小狐狸车手头雕
4. **`tree.glb`**：立体剪纸松树

### 特性：
- **零报错降级**：若未放入任何 `.glb` 文件，游戏将 100% 保留原生高精细程序化折纸模型正常运行。
- **自动归一化**：模型加载后自动根据目标尺寸缩放，并自动将底面对齐到地面原点。
- **自动套折纸材质**：自动为网格几何体补全 UV 投影，并注入逆光透纸、纤维凹凸与多面体切面（Flat Shading）光影。
